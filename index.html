文章生图自动化项目

基于 Trae / Cursor 的全自动化 WordPress 配图解决方案。你只需输入指令，代码自动运行。

快速开始 (Trae 交互模式)

本项目已针对 Trae 进行了优化。你无需手动敲击所有命令，直接将 Prompt 复制给 AI 即可。

01. 初始化环境

You
Prompt 复制代码 我在当前目录下克隆了项目，请帮我安装 Node.js 和 Python 的所有依赖，并检查环境是否正常。
AI
Trae Action 没问题，我将依次运行 npm install 和 pip install，并验证版本。
TERMINAL 
# 1. 安装 Node.js 依赖
npm install

# 2. 安装 Python 依赖 (建议使用 venv)
pip install -r requirements.txt

02. 配置密钥

You
Prompt 复制代码 请根据 `.env.example` 创建一个 `.env` 文件。我的 API Key 是 `sk-xxxx`，模型使用 `dall-e-3`。
AI
Trae Action 已为你创建 `.env` 文件并填入配置。请确认文件内容。
.ENV 
OPENAI_API_KEY=your-openai-api-key
OPENAI_IMAGE_MODEL=dall-e-3
OPENAI_BASE_URL=https://api.openai.com/v1
安全提示

永远不要将 .env 文件分享给他人，也不要提交到 Git 仓库！

03. 配置 WordPress 站点

You
Prompt 复制代码 我要配置一个新站点 `mysite.com`。请复制模板文件，并帮我生成配置 JSON。
BASH 
cp configs/template.env configs/mysite.com.env
cp configs/template.json configs/mysite.com.json
如何获取 WordPress 应用密码
  1. 登录 WordPress 后台 → 用户 → 个人资料
  2. 滚动到"应用密码"部分
  3. 输入名称（如"文章配图工具"），点击"添加新应用密码"
  4. 复制生成的密码（格式：xxxx xxxx xxxx xxxx）

04. 运行自动化流程

这是最关键的一步，你可以直接让 Trae 读取草稿并执行。

You
Prompt 复制代码 列出 `mysite.com` 的草稿文章，然后为 ID 为 123 的文章生成配图方案。
AI

规则与 SKILL

什么是规则？

规则是项目级别的约束和指导原则，存储在 .trae/rules/ 目录下。

  • 01-architecture.md - 核心流程与架构
  • 02-placement-rules.md - 自动化插图规则
  • 03-prompt-engineering.md - Prompt 生成第一原理
  • 04-visual-style.md - 视觉风格规范
  • 05-safety-operations.md - 安全操作边界
  • 06-metadata-seo.md - 图片元数据与 SEO 规范

什么是 SKILL？

SKILL 是可复用的 AI 能力模块，存储在 .trae/skills/ 目录下。

  • article-audit - 审核文章插图是否符合规范
  • baoyu-article-illustrator - 分析文章并生成配图方案
  • baoyu-image-gen - AI 图片生成

MCP 工具

MCP (Model Context Protocol) 工具允许 AI 访问外部服务，扩展项目能力。很多 MCP Server 需要 Python 环境运行。

常见问题

Q1: 为什么需要同时安装 Node.js 和 Python？

A: Node.js 用于处理并发高的 CLI 任务和网络请求（如 WordPress API），而 Python 用于处理复杂的 AI 任务和图像运算（如 OpenCV, Pillow），两者结合效率最高。

Q2: 安装依赖时报错怎么办？

A: 清除缓存重试：

npm cache clean --force
npm install
