快速开始 了解功能

⚡ 快速开始

5 分钟上手指南

按照以下步骤，快速搭建你的 WordPress 文章自动化系统

1

准备环境

确保你已经安装了 Node.js (v18+) 和 Python (3.8+)

2

克隆项目

git clone https://github.com/evolution301/article-automation.git
3

安装依赖

npm install
4

配置环境

复制 configs/example.env 到 configs/your-domain.env 并填写配置

5

运行系统

npm run start -- --site your-domain.com

🔧 安装配置

系统要求

  • Node.js 18.0 或更高版本
  • Python 3.8 或更高版本
  • WordPress 站点管理员权限
  • OpenAI API 密钥（用于图片生成）
  • 足够的磁盘空间用于存储生成的图片

安装步骤

1. 安装 Node.js

访问 nodejs.org 下载并安装最新 LTS 版本

2. 安装 Python

访问 python.org 下载并安装 Python 3.8+

3. 克隆项目

git clone https://github.com/evolution301/article-automation.git cd article-automation

4. 安装依赖

npm install

配置说明

系统使用配置文件来管理不同站点的设置。配置文件分为两类：

环境配置 (.env)

存储敏感信息，如 API 密钥、数据库凭证等

# configs/your-domain.com.env WORDPRESS_URL=https://your-domain.com WORDPRESS_USERNAME=admin WORDPRESS_PASSWORD=your-password OPENAI_API_KEY=sk-... GOOGLE_API_KEY=...

业务配置 (.json)

存储业务逻辑配置，如核心产品映射、风格定义等

{ "coreProduct": "eyeglasses", "style": "B2B commercial photography", "aspectRatio": "16:9" }

📖 使用指南

基本命令

处理单篇文章

npm run start -- --site your-domain.com --article-id 12345

批量处理文章

npm run start -- --site your-domain.com --batch

清理文章插图

npm run clean -- --site your-domain.com --article-id 12345

查看帮助

npm run start -- --help

工作流程

系统按照以下流程处理文章：

1

获取文章内容

从 WordPress 获取文章的完整内容，包括标题、正文、分类等

2

分析文章结构

识别 H2 章节标题，排除前言、结论、FAQ、CTA 等区域

3

生成图片 Prompt

基于核心产品和章节内容生成高质量的图片描述

4

生成图片

使用 OpenAI 或 Google API 生成高质量图片

5

上传图片

将图片上传到 WordPress 媒体库，并设置 SEO 元数据

6

插入图片

将图片插入到对应 H2 章节的正上方

✨ 核心功能

多站点支持

系统支持同时管理多个 WordPress 站点，每个站点有独立的配置文件

  • 通过 --site 参数切换站点
  • 独立的配置文件管理
  • 独立的图片存储路径
  • 支持不同站点的不同业务规则

智能插图

系统会自动分析文章结构，为每个 H2 章节生成合适的插图

  • 自动识别 H2 章节标题
  • 基于章节内容生成相关图片
  • 智能避让前言、结论、FAQ、CTA 等区域
  • 每章节仅限一张图片

Prompt 工程

系统使用先进的 Prompt 工程技术，确保生成的图片质量

  • 核心产品优先原则
  • 语义深度关联
  • 禁止文字覆盖
  • B2B 写实商业摄影风格

SEO 优化

系统自动为图片添加 SEO 元数据，提升搜索引擎排名

  • 优化的文件名（包含关键词）
  • 描述性 ALT 文本
  • SEO 友好的图片标题
  • 多语言支持

安全操作

系统提供多种安全机制，防止误操作

  • 基于白名单的精确删除
  • 禁止全局删除命令
  • 仅移除图片相关标记
  • 保护其他 Gutenberg 区块

📋 规则说明

自动化插图规则

系统遵循严格的插图规则，确保插图位置合理

插图位置

每篇 WordPress 文章的每个 H2 章节仅限一张图，且必须插入在 H2 标题的正上方

严格禁止区

严禁在以下区块生成或插入图片：

  • 前言 (Introduction)
  • 结论/总结 (Conclusion / Final Thoughts)
  • 常见问题 (FAQ / Frequently Asked Questions)
  • CTA 区块（具有特定背景色、白色文字和转化按钮的引导块）

Prompt 生成规则

系统使用第一原理生成高质量的图片 Prompt

核心产品优先

每一张图片的 Prompt 必须首先明确文章的"核心产品"（Core Product），所有视觉描述必须围绕该产品展开

语义深度关联

必须从 H2 章节下方提取前 200 个字符的正文内容融入 Prompt，确保图片内容与文章细节完美匹配

禁止文字覆盖

视觉描述中必须包含严格的负面约束，严禁生成任何文字、字母、水印或人工覆盖层

视觉风格规范

系统采用 B2B 写实商业摄影风格

标准风格

  • B2B 写实商业摄影风格
  • 高端摄影棚灯光
  • 产品细节清晰锐利
  • 背景专业干净
  • 展现真实的材质质感（如 TR90、乙酸酯、玻璃、金属等）

严禁风格

  • 严禁任何科幻、未来感、赛博朋克或抽象概念元素
  • 严禁使用 3D 渲染、插画、卡通或魔法特效
  • 严禁出现人脸、人物或任何形式的视觉幻觉

❓ 常见问题

如何配置多个站点？

为每个站点创建独立的配置文件：configs/domain1.env 和 configs/domain1.json。使用 --site domain1 参数来指定要操作的站点。

图片存储在哪里？

图片存储在 IMAGE/<domain>/<article-slug>/ 路径下，每个站点和每篇文章都有独立的存储目录。

如何自定义图片风格？

在站点的 JSON 配置文件中修改 style 字段，可以自定义图片的视觉风格。系统默认使用 B2B 写实商业摄影风格。

如何批量处理文章？

使用 --batch 参数可以批量处理文章。系统会自动获取所有需要处理的文章列表，并逐个处理。

如何清理已生成的插图？

使用 npm run clean -- --site your-domain.com --article-id 12345 命令可以清理指定文章的插图。系统会基于白名单精确删除，不会影响其他图片。

支持哪些图片生成 API？

系统支持 OpenAI DALL-E 和 Google Imagen 两种图片生成 API。你可以在配置文件中选择使用哪种 API。
