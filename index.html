文章生图自动化项目

基于 Trae / Cursor 的全自动化 WordPress 配图解决方案。你只需输入指令，代码自动运行。

核心功能

🎯 自动化策划

根据文章内容自动生成配图方案，智能识别章节结构和核心产品。

🖼️ 批量生成 (Python)

调用 Python 脚本进行图像生成与后处理（裁剪、压缩），支持断点续传。

☁️ 智能上传

上传图片到 WordPress 媒体库，具备自动去重和元数据更新功能。

📍 精准插入

根据章节标题将图片插入到文章的合适位置，智能避让特殊区块。

环境安装 (Hybrid)

系统要求

  • Node.js >= 18.0.0 (TS 运行时)
  • Python >= 3.10 (AI 与图像处理)
  • npm / pnpm / bun（任选其一）
  • 稳定的网络连接

Node.js Check

node --version

Python Check

python --version

安装项目依赖

TERMINAL 
# 1. Node 依赖
npm install

# 2. Python 依赖 (OpenCV, Pillow, Requests)
pip install -r requirements.txt

规则与 SKILL

配置 AI 大脑

将以下规则文件放置在 .trae/rules/ 目录下，确保 AI 遵循你的设计规范。

必需的规则文件

  • 01-architecture.md - 核心流程与架构
  • 02-placement-rules.md - 自动化插图规则
  • 03-prompt-engineering.md - Prompt 生成第一原理
  • 04-visual-style.md - 视觉风格规范
  • 05-safety-operations.md - 安全操作边界
  • 06-metadata-seo.md - 图片元数据与 SEO 规范

必需的 SKILL

放置在 .trae/skills/ 目录下：

  • article-audit - 审核文章插图是否符合规范
  • baoyu-article-illustrator - 分析文章并生成配图方案
  • baoyu-image-gen - AI 图片生成

MCP 工具

MCP (Model Context Protocol) 工具允许 AI 访问外部服务。请确保在 mcp_config.json 中配置以下服务。

You
Prompt 请检查 MCP 状态，并使用 `tavily_search` 搜索最新的 WordPress REST API 文档。

推荐安装的 MCP Server

  • mcp_tavily_tavily_search - 网络搜索
  • mcp_tavily_tavily_extract - URL 内容提取
  • mcp_GitHub_search_repositories - 搜索仓库
  • mcp_filesystem_read_file - 读取本地文件

快速开始 (Trae 交互模式)

环境配置完毕后，你可以通过与 Trae 对话来控制整个自动化流程。

01

配置密钥 (.env)

You
Prompt 复制代码 请根据 `.env.example` 创建 `.env`。API Key: `sk-xxxx`, Model: `dall-e-3`。
.ENV
OPENAI_API_KEY=your-openai-api-key
OPENAI_IMAGE_MODEL=dall-e-3
OPENAI_BASE_URL=https://api.openai.com/v1
02

配置 WordPress 站点

You
Prompt 复制代码 我要配置站点 `mysite.com`。请复制模板并生成配置文件。
BASH
cp configs/template.env configs/mysite.com.env
cp configs/template.json configs/mysite.com.json
03

运行自动化流程

列出草稿文章并执行生成：

TERMINAL
# 列出草稿
npx tsx scripts/cli.ts drafts:list --site mysite.com

# 为文章 123 执行生图
npx tsx scripts/cli.ts workflow:full 123 --site mysite.com
部署完成！

你已经成功运行了第一个自动化任务。现在可以尝试批量处理多篇文章。

路径配置

重要提示

项目使用相对路径，确保在不同操作系统上都能正常工作。

项目目录结构

项目根目录/
├── IMAGE/              # 图片存储目录（自动创建）
├── configs/             # 配置文件
├── scripts/             # TypeScript 脚本文件
├── python_core/         # Python 处理脚本
├── requirements.txt     # Python 依赖列表
└── ...

不同操作系统的路径

  • Windows: C:\Users\Username\Project\
  • macOS: /Users/Username/Project/
  • Linux: /home/username/Project/

最佳实践

安全注意事项

  • 保护 API 密钥，不要将 .env 文件分享给他人
  • 定期更换 API 密钥
  • 仅授予 WordPress 应用密码必要的权限
  • 执行批量操作前先备份 WordPress

质量控制

  • 检查生成的图片是否符合 B2B 风格
  • 确保没有文字、水印
  • 验证产品细节清晰
  • Alt 文本不超过 125 字符
  • Title 包含关键词

常见问题

Q1: 为什么需要同时安装 Node.js 和 Python？

A: Node.js 用于处理并发高的 CLI 任务和网络请求（如 WordPress API），而 Python 用于处理复杂的 AI 任务和图像运算（如 OpenCV, Pillow），两者结合效率最高。

Q2: 安装依赖时报错怎么办？

A: 清除缓存重试：

npm cache clean --force
npm install
