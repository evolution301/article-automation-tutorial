快速开始

1 安装依赖

打开终端，进入项目目录，运行以下命令：

npm install
2 配置环境

编辑 configs/.env 文件，填入你的 API 密钥：

OPENAI_API_KEY=your-openai-api-key
OPENAI_IMAGE_MODEL=dall-e-3
OPENAI_BASE_URL=https://api.openai.com/v1
重要提示：不要将 .env 文件分享给他人，保护好你的 API 密钥！
3 配置站点

复制站点配置模板：

cp configs/template.env configs/your-site.com.env
cp configs/template.json configs/your-site.com.json

然后编辑 configs/your-site.com.env，填入 WordPress 站点信息：

WP_SITE_URL=https://your-site.com
WP_USERNAME=your-username
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx
如何获取 WordPress 应用密码：
  1. 登录 WordPress 后台
  2. 进入：用户 → 个人资料
  3. 滚动到"应用密码"部分
  4. 输入名称（如"文章配图工具"），点击"添加新应用密码"
  5. 复制生成的密码（格式：xxxx xxxx xxxx xxxx）
4 开始使用

列出草稿文章：

npx tsx scripts/cli.ts drafts:list --site your-site.com

生成配图方案（告诉 AI）：

"为 Post 123 生成配图方案，站点是 your-site.com"

执行完整流程：

npx tsx scripts/cli.ts workflow:full 123 --site your-site.com
恭喜！你已经完成了快速开始！

现在可以继续阅读下面的详细教程，深入了解项目的所有功能。

安装配置

系统要求

  • Node.js >= 18.0.0
  • npm / pnpm / bun（任选其一）
  • 稳定的网络连接
  • WordPress 站点访问权限

安装 Node.js

从官网下载并安装最新 LTS 版本：

https://nodejs.org/

安装后验证版本：

node --version

安装依赖

进入项目目录，运行：

npm install
💡 推荐使用 pnpm： 
npm install -g pnpm
pnpm install

验证安装

测试 tsx 是否可用：

npx tsx --version

测试 CLI 命令：

npx tsx scripts/cli.ts --help

使用教程

第一步：列出草稿文章

查看 WordPress 中的所有草稿文章：

npx tsx scripts/cli.ts drafts:list --site your-site.com

这将显示所有草稿文章的 ID 和标题。

第二步：生成配图方案

告诉 AI 为指定文章生成配图方案：

"为 Post 123 生成配图方案，站点是 your-site.com"

AI 会自动分析文章内容并生成 IMAGE/your-site.com/<article-slug>/outline-123.md 文件。

第三步：执行完整流程

运行自动化脚本，处理单篇文章：

npx tsx scripts/cli.ts workflow:full 123 --site your-site.com

这个命令会依次执行：

  1. 同步文章标题到 outline
  2. 生成缺失的图片
  3. 清理旧的媒体文件
  4. 上传图片并插入文章

批量处理多篇文章

如果有多篇文章需要处理，可以指定多个 ID：

npx tsx scripts/cli.ts workflow:full 123 456 789 --site your-site.com

验证文章状态

检查图片插入状态和 SEO 信息是否完整：

npx tsx scripts/cli.ts posts:verify --site your-site.com

路径配置

⚠️ 重要提示：项目使用相对路径，确保在不同操作系统上都能正常工作。

项目目录结构

项目根目录/
├── IMAGE/              # 图片存储目录（自动创建）
├── configs/             # 配置文件
├── scripts/             # 脚本文件
└── ...

不同操作系统的路径

  • Windows: C:\Users\Username\Project\
  • macOS: /Users/Username/Project/
  • Linux: /home/username/Project/

遇到路径问题怎么办？

告诉 AI 你的实际情况：

"我的项目路径是：/Users/john/projects/article-automation
请帮我检查并更新所有文档中的路径"

AI 会自动帮你修复路径问题。

规则与 SKILL

什么是规则？

规则是项目级别的约束和指导原则，存储在 .trae/rules/ 目录下。

  • 01-architecture.md - 核心流程与架构
  • 02-placement-rules.md - 自动化插图规则
  • 03-prompt-engineering.md - Prompt 生成第一原理
  • 04-visual-style.md - 视觉风格规范
  • 05-safety-operations.md - 安全操作边界
  • 06-metadata-seo.md - 图片元数据与 SEO 规范

什么是 SKILL？

SKILL 是可复用的 AI 能力模块，存储在 .trae/skills/ 目录下。

  • article-audit - 审核文章插图是否符合规范
  • baoyu-article-illustrator - 分析文章并生成配图方案
  • baoyu-image-gen - AI 图片生成

如何创建自定义规则？

在 .trae/rules/ 目录下创建新的 .md 文件：

# 你的规则标题

## 规则目的
简要说明这条规则的目的。

## 核心要求
- 要求 1
- 要求 2

## 禁止事项
- ❌ 禁止行为 1
- ❌ 禁止行为 2

如何创建自定义 SKILL？

在 .trae/skills/ 目录下创建新的 SKILL 目录和 SKILL.md 文件：

---
name: your-skill-name
description: 简短描述这个 SKILL 的功能
---

# SKILL 标题

## 功能描述
详细描述这个 SKILL 的功能。

## 输入参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| param1 | string | 是 | 参数说明 |

## 输出格式
描述 SKILL 的输出格式。

常见问题

安装相关问题

Q1: Node.js 版本要求是什么？

A: 需要 Node.js >= 18.0.0。检查版本：

node --version

Q2: 安装依赖时报错怎么办？

A: 清除缓存重试：

npm cache clean --force
npm install

配置相关问题

Q3: 如何获取 WordPress 应用密码？

A: 按照以下步骤：

  1. 登录 WordPress 后台
  2. 进入：用户 → 个人资料
  3. 滚动到"应用密码"部分
  4. 输入名称，点击"添加新应用密码"
  5. 复制生成的密码

Q4: WordPress API 认证失败怎么办？

A: 检查以下几点：

  • 应用密码是否正确
  • 用户名是否正确
  • 站点 URL 是否正确
  • 用户是否有足够的权限

使用相关问题

Q5: 图片生成失败怎么办？

A: 检查以下几点：

  • API 密钥是否有效
  • API 余额是否充足
  • 网络连接是否正常
  • Prompt 是否符合规范

Q6: 图片没有插入到文章怎么办？

A: 检查以下几点：

  • outline 文件中的"插入图片位置"是否与文章 H2 标题完全匹配
  • 文章是否包含该 H2 标题
  • 是否触发了避让规则（CTA、FAQ 等）

Q7: 如何删除已插入的图片？

A: 使用清理命令：

# 移除文章中的图片块
npx tsx scripts/cli.ts posts:clean 123 --site your-site.com

# 删除媒体库中的图片
npx tsx scripts/cli.ts media:purge --names=hero-123.png --site your-site.com

成本与性能

Q8: 如何控制 API 成本？

A: 以下是一些优化建议：

  • 使用断点续传，已生成的图片不会重新生成
  • 选择便宜的 API（Google Gemini 通常比 OpenAI 便宜）
  • 批量处理，减少 API 调用次数
  • 测试环境先验证，避免浪费

Q9: 如何提高执行速度？

A: 以下是一些优化建议：

  • 使用 pnpm 或 bun，比 npm 更快
  • 批量处理多篇文章
  • 确保网络连接稳定
  • 减少重试，配置合理的超时时间
💡 更多问题：查看 FAQ.md 文件了解更多常见问题和解决方案。

最佳实践

安全注意事项

  • 保护 API 密钥，不要将 .env 文件分享给他人
  • 定期更换 API 密钥
  • 仅授予 WordPress 应用密码必要的权限
  • 执行批量操作前先备份 WordPress

操作注意事项

  • 所有脚本可重复执行，不会产生重复内容
  • 图片生成支持中断后继续
  • 已上传的图片不会重复上传
  • 已插入的图片不会重复插入

质量控制

  • 检查生成的图片是否符合 B2B 风格
  • 确保没有文字、水印
  • 验证产品细节清晰
  • Alt 文本不超过 125 字符
  • Title 包含关键词
