文章生图自动化项目

基于 AI 的全自动化 WordPress 文章配图解决方案，集成 OpenAI DALL-E 3 与 MCP 协议。

项目状态

当前版本为学员版 v1.0。请确保在 Node.js 18+ 环境下运行。

快速开始

只需三步，即可将自动化工作流集成到你的本地环境中。

1. 安装依赖

克隆项目后，使用包管理器安装所需依赖。

BASH
# 进入项目目录
cd article-automation

# 安装依赖
npm install
2. 配置环境变量

复制 .env.example 文件并填入你的 API Key。

ENV
OPENAI_API_KEY=sk-your-key-here...
OPENAI_IMAGE_MODEL=dall-e-3
WP_SITE_URL=https://your-site.com
3. 运行测试

使用 CLI 工具检查草稿箱连接状态。

BASH
npx tsx scripts/cli.ts drafts:list

核心功能

自动化策划

智能分析文章结构，自动识别核心产品与章节，生成最匹配的配图方案。

批量生成

支持多线程处理，断点续传功能确保在网络不稳定时也能完成任务。

智能上传

自动去重上传至 WordPress 媒体库，并自动填写 Alt Text 提升 SEO。

安全提示

请勿将包含 API Key 的 .env 文件提交到 Git 仓库。建议将其加入 .gitignore 文件中。
